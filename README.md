# ABCVIP – Trung tâm ưu đãi (giao diện mẫu)

## Tính năng
- Giao diện responsive cho điện thoại và máy tính, tông trắng/hồng/đỏ.
- Nhập tên tài khoản khách.
- Chọn chương trình: nạp đầu 200%, 88K trải nghiệm, điểm thưởng hoặc ưu đãi riêng.
- Tạo thông báo **đã tiếp nhận yêu cầu**, sao chép nội dung, nhập tài khoản khác.

## Lưu ý quan trọng
Đây là website tĩnh chạy ở trình duyệt. Trang không kết nối hậu đài, không kiểm tra tài khoản thật và không cộng điểm/tiền thưởng. Chỉ thông báo ưu đãi đã được cộng sau khi có xác nhận từ hệ thống có thẩm quyền.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Tải `index.html` lên thư mục gốc của repository.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, rồi Save.
5. Chờ GitHub Pages xuất bản website và mở URL được cung cấp.
